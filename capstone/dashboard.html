Limitations

  • Synthetic data. The method is shown, but these rates are not real-world evidence.
  • Association, not causation. Only a pilot with a holdout group can show an action reduces churn.
  • The score ranks, it does not predict. A score of 60 is not a 60% chance of leaving.
  • Assumed inputs. Save rate, contact cost and the 12-month value of a save drive the result. Read the range, not a single figure.
  • Hand-set thresholds (30% login drop, 21 days inactive) need review on real outcomes, and production inputs must be measured before the churn window.
